# 视觉导演 V1.0 实施计划（已批准设计）

目标：从数学教师的 TeachingPackage v1.0 生成无 AI、无渲染依赖的 StoryboardPlan，并保持可测试、可重复、可追溯。

## 约束
- 不修改数学教师代码，不改变其参考解析和公式，不引入新解法。
- 白色电子白板；题干顶部固定、默认居中、长题左对齐并换行；字幕区与口播数据分离；数学字幕保留 LaTeX；结论不加框。
- 计算/矩阵/证明/图形/概率五种策略。图形必须显式提供数学几何数据，按需出现，绝不猜测数值或凭空作图。
- 无 WAV、TTS、Manim、MP4、前后端；无秒数估计。以 speech_unit_id 做语义同步锚点。
- 原矩阵和变换结果保留；长证明保留关键结果，空间不足时滚动/归档；不能省略证明。
- 标签不能与无关线、点和其他标签重叠；数学上必要的相交允许。

## 任务与验证
1. 定义输入适配、独立数据合同和命令行：编写测试 -> 确认失败 -> 实现 -> 测试通过。
2. 设计画布安全区域、题目区与五类布局策略：测试极长题干/矩阵/证明/知识点/图形按需 -> 实现 -> 测试。
3. 按教学事件将 math_objects、board_actions 转为确定性画面动作，并提供板书滚动、归档与口播锚点：测试未来源对象、未来提前显现、无法对应的变形 -> 实现 -> 测试。
4. 几何显式原语及标签避让：测试标签冲突、超出区域、无法放置 -> 实现 -> 测试。
5. 字幕与口播严格隔离，数学片段保留 LaTeX；仅复制教师 subtitle parts；测试文本一致性与独立显示 -> 实现 -> 测试。
6. 运行真实极限题的 TeachingPackage 示例及五类场景的构造样例；执行整包测试、编译、JSON Schema 生成、CLI；代码评审后提交独立分支，创建草稿 PR（不合并）。

## 无法凭当前输入自动保证的事
- 教师模块目前不输出可任意变换的数学子表达式映射或真实音频时间码；无法形式验证数学动画等价和口播精确秒级同步。故变形采用安全降级。
- 教师模块没有绘图原语；无显式 DiagramSpec 时禁止凭问题类型创建坐标图。
- 几何避让先在逻辑图表坐标中校验；实际像素与字体度量仍需后续渲染阶段再次检查。
