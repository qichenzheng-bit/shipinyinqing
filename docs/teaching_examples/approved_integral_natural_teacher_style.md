# 已确认的教师语言风格：定积分换元示例

> 这是真实课堂**语言风格与教学逻辑的审阅基准**。数学内容必须依输入题目和参考解析生成，不能把该积分题当作其他题型的固定模板。完整的可执行逐动作口播以 `animation_engine/tools/build_novel_substitution_integral.py` 为准；渲染前的权威讲稿仍由 `export-spoken-script` 从该课程源生成。

题目：\(\displaystyle I=\int_0^2 2xe^{x^2}\,dx\)。

**开场：**“同学们大家好，我们先来看一下这道定积分题。” 随即忠实朗读原题，不用“我们来读一下题目”之类的报幕。

**思考引导：**“这道题我们先观察一下被积函数的结构。这里有一个 \(e^{x^2}\)，前面还有 \(2x\)。我们知道，\(x^2\) 对 \(x\) 求导，结果是 \(2x\)。再看前面的系数，恰好也是 \(2x\)。也就是说，指数里面的函数和它的导数同时出现。遇到这样的结构，我们可以把 \(x^2\) 作为一个整体，换成新的变量。这样原积分就会化成更简单的指数函数积分。这种方法，就是换元法。”

**知识点：**“这里回顾一下定积分换元法。令 \(u=g(x)\)，那么 \(du=g'(x)\,dx\)。定积分换元不仅要换被积函数和微分，还要同步改变积分上下限。”

**应用：**“回到这道题，令 \(u=x^2\)，那么 \(du=2x\,dx\)。原来的 \(2x\,dx\) 可以直接用 \(du\) 代替。不过这是定积分，上下限也要换。当 \(x=0\) 时，\(u=0\)；当 \(x=2\) 时，\(u=4\)。”

**易错点：**“有些同学换元以后，只改了被积函数，却把原来的积分限直接保留下来，这是不对的。现在积分变量已经换了，上下限必须用新的变量关系重新计算。这里上限由二变成四。”

**计算：**
\[
I=\int_0^4 e^u\,du
 =\left[e^u\right]_0^4
 =e^4-e^0
 =e^4-1.
\]
每一条首次新增板书公式都要在其写入时完整读出，关键代入结果不得跳步；保留已有内容但不需要逐字重复。

**结论：**“所以本题最终结果是 \(e^4-1\)。这样，这道题就算出来了。”

**归纳总结：**“最后我们简单回顾一下。关键是发现内层函数和它的导数同时出现，从而想到换元法。定积分换元以后，上下限也必须同步改变。这是本题最容易出错的地方。好，这道题我们就讲到这里。”

**反例规则：**禁止尚未阐述数学依据就突然反问“为什么考虑换元法呢”；禁止“现在我们来读一下题”“其公式为”“把上一页移到计算区”等不自然的流程介绍。整体讲解先讲**为什么**，然后才讲**怎么做**。
