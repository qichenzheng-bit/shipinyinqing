# V2.5.1 多项积分和复杂连续计算：已实现的方案与验收范围

## 本次开发范围

本版保留已经验收的完整教学单元、黑色 MathTex 计算、固定题干、写满再擦黑板模式。在其上新增显式 **多项计算结果账本**，而不是让动画引擎私自拆分积分或生成数学结论。不接入 AI 解题、TTS、真实字幕，也不修改 main。

## 核心代码

- animation_engine/src/animation_engine/computation_groups.py：版本化且严格的分项语义合同。由教师审核原题拆项、每项有序事件、独立结果、可安全换板的子目标终点和计算 checkpoint、最终合并式；严格校验对象来源哈希及所有事件覆盖，禁止提前引用未来结果。
- animation_engine/src/animation_engine/persistent_chalkboard.py：同一教学单元完整写完且保持不动；若板书装不下，允许在教师批准的子目标边界换页；换页时只根据账本重新写出已完成的真实结果和必要计算中间式。若必须继承的内容仍放不下，明确报错而不是偷偷删除。
- 多于三项且跨页承接过于拥挤时，支持教师预先审核的 recap 汇总承接式：所有分项完成后，使用原始 MathTex 数学对象写出已算结果；下一页只需重写这条完整表达式继续化简。不允许未完成分项时提前出现 recap。
- animation_engine/src/animation_engine/cli.py：计划与真实 MP4 都增加可选 --computation-groups 参数。不指定时沿用旧课堂调用签名，保持兼容性。
- animation_engine/tools/build_multipart_integral_lesson.py：A/B/C 三套独立教材和演示包生成器。

## 三套新题

案例 A：从 0 到 1 积分 xe^x+x/(1+x²)+x²。三项分别使用分部积分、换元并更换积分上下限、基础幂积分，求得 4/3 + (ln 2)/2。
案例 B：从 0 到 1 积分 x+x²e^x+sin x。重点是 x²e^x 的两次连续分部积分，中间 checkpoint 为 I₂=e−2J，J=∫xe^x；最终得 e−1/2−cos 1。中间目标可在审核断点跨页，不得拆掉某次分部积分的边界和结果。
案例 C：从 0 到 1 积分 xe^x+x/(1+x²)+x²+sin x+e^x。五项测试动态结果账本及教师确认的汇总承接式。最终得 e+4/3+(ln 2)/2−cos 1。其复杂性主要是分页和结果容量压力，而非强迫把简单项拆成大量事件。

## 新增失败保护

- 源哈希不匹配、额外/重复事件、尚未算出的分项结果、提前汇总、重复结果 ID 都必须拒绝。
- 若同一分项中的连续教学单元需要换板，但没有经过教师审核的 safe_break_after/checkpoint，则拒绝，不能随意切在计算中间。
- 已完成的分项结果和中间关系若没有容纳空间，拒绝并要求教师使用已审核的 recap 或重新设计合法布局，不能无限缩小、丢结果或剪掉公式。
- 图片、矩阵及复杂证明仍使用明确专属版式，不假装本阶段已经支持。

## 验收

全部 teacher、visual_director、animation_engine 原回归 + V2.5.1 专项负面测试。SymPy 独立验证 A/B/C 总积分及关键子项。三套新题均用真实 MathTex 字形完成分页预检；A、B 输出真实 Manim 1280×720、30FPS 完整 MP4 并截取关键画面，C 保留完整源码、账本、布局 JSON，待更高阶综合验收可进一步渲染完整 MP4。

本阶段测试确认的是人工审核数学内容与确定性动画的一致性，不能取代未来的数学教师自动解题验证，也不能声称音轨或字幕已经同步。
