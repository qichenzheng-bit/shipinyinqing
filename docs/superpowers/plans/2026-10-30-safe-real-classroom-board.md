# 真实课堂板书：碰撞消除、紧凑布局及四色讲解规范

## 用户反馈与设计约束

当前视频存在数学对象重叠、固定题干与中部思路讲解空距过大，且知识点/思维引导/易错点/总结缺少统一字级与独立颜色。用户希望参照真实课堂，解析过程的数学符号与说明必须为黑色。

## 已改造结构

1. 不再为简单题创建常驻题干下方提示栏。概念段落在需要时进入黑板主体，以原教师事件和来源哈希为依据。每种提示使用固定 18px 标题和固定 16px 解释文字，数学公式由 Manim MathTex 原对象写入。
2. 题干与概念段落缩短间距：原讲解标题始于 y=286px，改为 y=150px（1280×720画面），下面解释约 y=183px，MathTex 根据实际中文字形底边计算，留至少 25px 间隔。不允许固定魔法坐标使解释和公式重叠。
3. 类别色固定：思维引导 #2563EB 蓝色；核心知识点 #7C3AED 紫色；易错点 #DC2626 红色；归纳总结 #0F766E 绿色。结果检查仍为琥珀色 #D97706；观察为中性灰。所有数学、题干及说明均用纯深黑 #111111，禁止渲染器临时把正式解题公式涂成其他颜色。
4. 修复上下文公式碰撞时序：新数学对象在知识点位置下方真实写出，旧对象在这段时间不显示；解释结束先将新对象平滑移至目标版面，后台完成旧对象的更新与去除，再恢复仍需展示的旧板书。原对象不会重复 Write 或丢失来源。
5. 添加板书位移轨迹安全判断。保留对象之间如果位移中间会相交，使用渐隐—不可见重排—渐显，拒绝两个公式互相穿越。布局端仍检查各个目标对象的静态几何不重叠。
6. 为可能同事件新增的多条数学公式增加逐式堆叠方案；同一个知识点中多个 MathTex 不能画在同一坐标。超过容纳高度时显式报错。

## 验收方式

独立于 main 的 `feature/classroom-safe-board-rules-v1` 分支，真实 GitHub Actions 包括旧测试回归、新增轨迹碰撞和四色类型测试、全片 Manim/FFmpeg 真实 MP4、四类教学概念正在展示时的实际帧（不是事件尾帧）、颜色像素容差检查，及 1280×720/30fps 的 ffprobe。

本阶段没有配音，所以不可以声称已经实现口播—字幕—板书严格同步。教学内容仍为原有独立核查的分部积分题，未改动数学推导；只是将已有带有『注意负号』的步骤明确标为易错点。
