# 考研数学真实课堂：从逐条公式到完整推导单元

## 问题复盘

先前已渲染的泰勒极限视频数学答案正确，但一条公式对应一次教学事件，导致局部三次/五次项系数孤立显示，真正关键的乘法展开反而没有完整写出；擦黑板还把本来一体的推导步骤分成两页。因而『动画渲染成功』不等于教学内容合格。

## 本次经过修改的代码契约

1. `animation_engine/src/animation_engine/classroom_teaching_units.py` 新增具有清晰教学目标和必要解题理由的**教学环节编译器**。一个教师教学事件可以拥有多条有序的 `board_action` 和多条真实 MathTex。每条公式分别拥有唯一 `math_object_id` 与 `source_step_ids`；口播语义只有本教学环节的一份，并不将每条简单运算伪造成独立知识点。
2. 判断某一环节是否值得独立讲解的标准，是其数学目的、所需依据和学生容易错在哪里；不能机械规定每个环节必须有两行或必须有一个标题。允许意义明确的一行知识点，也允许需要多步展开的完整计算。
3. `persistent_chalkboard.py` 以**完整教师事件**为自动擦板的不可拆单位。一个事件中的多条公式在同一页写完，原板书按“写上不消失”的既定规则保留。如果下一完整单元放不下，先擦板再展示整个单元；必要的已得结果在新页按原始 source ID 重写。
4. 在 plan/真实 MP4 manifest 中记录 `math_write_count`、`unit_source_step_ids`、`unit_heading`、`erase_reason`，以便审计一节视频到底拆分了多少教学目标和多少真正的数学书写动作。
5. 教师脚本的所有 LaTeX 仍由 MathTex 编译，不改数学内容来源，不加最终答案框；思维引导/知识点/易错点/归纳总结颜色、题干居中、黑色解题和字幕安全区域保持原有规则。教学提示不是实际生成的字幕，未配音不得声称完成音画同步。

## 修复旧泰勒演示

`animation_engine/tools/build_fresh_taylor_classroom.py` 已由原 19 次机械细分，改为 5 个完整教学环节，12 条实际数学书写。采用恒等式 `tan x - sin x = sin x (1 - cos x) / cos x` 的思路，把正弦、余弦及倒数展开与五次项的两个来源逐项相乘，完整写出再合并系数；最后才消去题目中的三次项。相关单测与真实 MathTex 排版检查都被加入 GitHub Actions。

## 全新题目独立验收（不同于此前积分与泰勒极限）

问题：解一阶线性微分方程初值问题 `y' + 2xy = 2x, y(0)=0`。作者先设计 4 个独立教学目标：识别线性方程和积分因子、展示乘积求导与对两边积分、利用初值确定常数、检验原方程和初值；共 11 条独立 MathTex 书写，不再重复抄写题干。关键第二单元内至少 4 条中间公式完整可见，不能从乘上因子直接跳到特解。

正确特解：`y=1-e^{-x^2}`，使用 SymPy 独立验证微分方程、初值及积分因子。同时检查每条数学原式的 source ID、书写顺序、页满擦板原因、乘积法则单元不可拆以及原有模块回归。

## 保留的边界

教学内容目前由人工编写并审核，编译器保证来源和呈现顺序，不具有自动证明每个中间步骤数学正确性的通用能力；本次新题另做独立符号检查。视频为无声音的 Manim 课堂视觉预览，后续 TTS 和字幕只能从真实口播独立对齐。复杂几何、长证明等仍需要专门版式，不应机械套用本次简单黑板策略。
