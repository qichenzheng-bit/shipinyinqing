# 考研数学真实课堂：整块黑板写满再擦

## 用户明确指定的新课堂规则

不要频繁做数学公式的淡入淡出、移动重排、隐藏后恢复等自动排版过渡。简单题作为一块真正的黑板：先出题，老师讲到哪里就在当前板面下方书写。写上的知识点、思维引导、易错点、结论、计算过程**一直保留**，只有一块黑板确实写满，才擦去当前板书并开始新一页。题干始终固定，不随着擦黑板消失。

## 实施与代码

增加独立的 `persistent_chalkboard` 布局/渲染实现，与原 2.4 及后续经典模式同时保留。`render-longboard`、`plan-longboard` 遇到显式 `guidance_style=persistent_chalkboard` 才进入这个严格模式，原调用不变。

- **仅追加**：每个教师事件从源步骤获得 MathTex，若该事件为思维引导、知识回顾、易错点、观察、检查、总结，则把核验后的中文说明与该次 MathTex 连在同一板面。其他计算直接顺序写公式；不用一个个弹出提示，不会擦掉以前的内容。
- **不移动旧字**：块首次布局后直到页满擦除，其 x/y、LaTeX、颜色和来源 ID 均不改变。新 MathTex 用 `Write` 写一次；当页的中文提示只出现一次，并一直保留。
- **实测分页**：布局使用 Manim 真正测量 MathTex 尺寸、准确页内位置、界限、来源合同哈希与所有已有板书块的碰撞判断。下一条完整教学事件放不下，才在事件边界执行擦黑板。不能只因为教学阶段发生改变而擦黑板，不能擦到半个公式。
- **擦黑板**：只在整板写满时执行一次横向白板擦除。画面外部叠加的原题仍然固定；已擦掉的旧字不会自动又回来。下一板若仍需已得到的关键结果，就用其已被审核的原始 MathTex 在新板重新书写，绝不提前泄露计算结果。
- **课堂字体与颜色**：题干和数学主体统一黑色；数学题干/计算保持同级 MathTex，思维引导蓝色、知识点紫色、易错点红色、归纳总结绿色，中文说明黑色，继续采用既定 18px 提示标题与 16px 说明文字。
- **现实限制**：本版仍是无真实配音的课堂视觉验收，不能声称音轨、字幕已经同步。对于长题、多栏图形、复杂几何，未来应根据每类黑板实际空间扩展，而不是强行给公式变小。
