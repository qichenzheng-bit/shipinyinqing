# V2.5.4 函数图像、积分区域、几何图形课堂

## 范围与用户已确认规范

承接已验收的 V2.5.1–2.5.3（积分、矩阵、长证明）最终代码；本阶段单独分支，PR 为 Draft，不合并 main。全项目必须保留：白色背景、顶部固定题干、题干与正文紧凑、数学变量及标签一律 MathTex、知识点显示真正通用公式、数学运算黑色、关键点按需说明、字幕与真实口播分离、写过的板书不突兀消失、跨页有源依据。图中名称、数字、点标签不能与线段/曲线重叠，也不能有单个标签横穿线段。

## 特有版式：真正的双数学区域

左侧文字推导和真正 MathTex，右侧保持一块独立的几何/函数图形空间，图形和板书都来自审核源数据。两个区域之间有明确安全间隔，**左侧公式不强行以整屏中心居中覆盖图形**；当图形被使用时，以左侧数学工作区域居中为准。与上一阶段没有图形的证明题（整屏水平中心为准）不矛盾。

坐标面板为 480×358 像素，采用统一归一化坐标，由来源数值直接转 Manim 点、直线、曲线、数学标签。曲线依照真实采样点绘制，不从题干文本生成或猜测函数。积分区域由来源中两条已有曲线及它们严格匹配的 x 采样点围成；验算上下关系、端点闭合和真实面积公式，不凭空涂一块看似合理的多边形。

- `classroom_teaching_units.py` 接受审核的 `diagram_specs`，经现有视觉导演和 `place_diagram` 建立冻结图形来源，并为每个事件保留原始数学/语音锚点。序列化为 JSON 之后必须能严格回读，已修复视觉导演的显式曲线采样点类型兼容问题。
- 新增 `diagram_classroom.py`：`verified_diagram_classroom` 来源合同，含原始 storyboard 哈希、教师已审核标记、图形类别、逐事件 `reveal_ids`、原始图形锚点、积分填充区域源曲线 ID。图形点、线、曲线、标签均只能引用冻结的 `scene.diagram` 对象，不能任意补画或改公式。
- 校验源点坐标、线端点、曲线采样数量与边界、退化线段、重复 ID、MathTex 点名与位置、点标签遮住线/曲线、完整分步来源、标签在点之前显示、区域在两边界曲线之前填充、区域上下关系错误、漏掉最后对象等情况，遇到错误明确阻止视频生成。
- `persistent_chalkboard.py` 把图形侧栏纳入真正的 `plan-longboard` / `render-longboard`。新增图形事件保持来源对象绘制顺序，支持用 Create / FadeIn 分次画出点、线、光滑曲线、MathTex 点名和区域填充；已经画过的内容持续显示至完整擦板。在发生整页擦除时，依照全部原始来源对象 ID 重新绘制已经完成的图形，再进行新事件。需要保证视频 manifest 可核查每个对象最初何时出现。
- CLI 新增 `--diagram-classroom`，与多项积分、矩阵、长证明专属合同严格互斥，没有经审核来源时不得静默渲染假图。

## 首次独立教学题目

- **A 抛物线与切线**：`f(x)=x²`，点 `P(1,1)`，由导数几何意义 `k=f'(x₀)` 得切线 `y=2x−1`。分别绘制坐标轴、抛物线、切点、切线，切点数值与导数斜率单独验证。
- **B 两曲线围成的面积**：`y=x`、`y=x²`、`0≤x≤1`，真实曲线点源绑定，上下曲线之间蓝色透明区域逐步填充，按通用面积公式 `S=∫(f−g)` 求得 `1/6`。参数、坐标、积分数值分别独立检验。
- **C 直角三角形的勾股定理**：四与三的直角边构成真实 3:4:5 像素比例的图形；A、B、C 点名须正确 MathTex 且不与边重叠，直角标记明确，通用 `a²+b²=c²` 公式和本题 `BC=5` 分离呈现。
