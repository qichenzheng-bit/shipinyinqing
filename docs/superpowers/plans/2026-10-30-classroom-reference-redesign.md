# 课堂效果重构：参考视频驱动的教学呈现

用户参考十段高中数学讲解视频，指出 2.4 虽有自动滚动切幕，但不是自然的数学教师课堂。本次重构将其定位为面向考研数学的真实教学呈现。

## 实现原则

1. 教师负责解题思路、知识原理、应用、实际推导和公式；数学源对象、原 LaTeX、来源步骤不可被渲染器改写。
2. 每个板书事件新增人工审核的思路提示：phase、heading、detail、source_step_ids、pause_seconds、write_seconds。提示仅承载中文文字，不混入任何未经 MathTex 渲染的数学符号。
3. 根据分镜与执行计划的 SHA 对思路提示追溯来源；如果输入事件缺失、来源不符或文本非法，拒绝渲染。
4. 页面固定题干，题干下方预留 112 像素的思路解释区域。每个事件可以是观察、策略选择、知识回顾、本题应用、逐步计算、检查、归纳等教学任务。
5. 板书仍通过 MathTex 实际 Write、移动、归档、切幕；预览加长关键步骤的阅读停留时间。提示面板不是语音字幕，不能以这份预览声称板书与配音已经严格同步。
6. 原 2.4 命令兼容保留；新增 render-longboard --classroom-cues 选项，旧调用不变。

## 本次完全新题

求定积分 I=∫₀¹ x² ln(1+x) dx。先由多项式乘对数选取分部积分法，随后作 x³/(1+x)=x²−x+1−1/(1+x) 的多项式除法，最后回代得到 I=2 ln 2/3−5/18。
新题经人工编写完整的14个教学事件与全部数学表达式，使用 SymPy 独立核验。绝不声称当前使用了在线 AI 教师自动解题。

## 视觉验收

由新的 GitHub Actions workflow 运行真实 MathTex 排版与 Manim MP4，保存 1280x720 / 30fps 的可观看视频、关键截图、教学包、分镜、源数据哈希和动作时间码。
本次只检验数学推导与教师提示如何在画面中配合，仍未接入真实语音、语音对齐后的字幕、动态图和矩阵/几何专项布局。

本阶段的成功条件是视觉自然、教学思路可追踪、公式无缺失与重叠，而不只是合成了一段 MP4。
