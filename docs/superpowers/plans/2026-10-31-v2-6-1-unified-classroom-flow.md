# V2.6.1 统一课堂流程编排方案及验收

## 开发目标

本阶段复用 V2.5.1～2.5.4 已验收的积分、矩阵、证明与函数图形能力，让**同一道题**能按教师给定的顺序切换图文解析与完整计算。首版不新增 AI 自动解题或选题，不改原排版引擎，不生成虚构语音或字幕。

## 教学合同

新增 animation_engine/src/animation_engine/unified_classroom_flow.py，接受教师审核的统一课程流程和完整数学来源。每一阶段保存：

- stage_id / engine / directory / package_sha256 / source_storyboard_sha256 / event_ids / handoff。
- engine 支持 diagram、computation、matrix、proof、standard，仍使用其原有经过验收的专属渲染合同；单阶段不可混用互斥的合同。
- 统一固定的数学题干与完整教师审核参考答案；每阶段依照教学包哈希、Storyboard 哈希、ExecutionPlan 与 cues 及 policy 独立检验。
- 跨段 handoff 指定上一段确实写出的 math_object_id 和下一段首个数学教学事件重写的 math_object_id；LaTeX 原文逐字一致，不因为“看起来等价”而擅自变化。
- 全局事件 ID、全局页码、明确的换板标记和阶段审计结果；拒绝跳阶段、未知模式、非法目录、同一段多种专用合同、假知识点、未证明数学结论和前后题干改变。

## 课堂切换

在图文混合区域转为全宽计算区域时，2.6.1 首版明确使用**教学阶段边界的白色横向擦板**，约 0.6 秒；擦板只擦数学工作区，不擦顶部固定题干，不黑屏，不提前出现下一阶段未写出的公式。

每段仍使用原始 Manim/MathTex 和保留写过的墨迹规则；最后通过 FFmpeg 生成一段真正的 1280×720、30 FPS 完整 MP4。统一 manifest 保存真实视频片段帧数、数学来源与全局事件时间码。图形和公式不能因合成而失去各自的源验证。

**边界声明**：更复杂的同页双模式布局、跨模式图形持续驻留、智能换板与局部重渲染属于 2.6.2～2.6.5；本阶段不冒充这些功能已完成。

## 首轮新综合题

先对 y=x、y=x² 在 0≤x≤1 围成的区域绘图，确认上下边界并展示**一般面积公式**，推导 S=∫₀¹(x−x²)dx；随后进入全宽纯计算课堂，以这个**一字不差、已展示过**的积分式开头，逐步拆项、计算上下限，得到 S=1/6。首段与第二段共享完全相同的题干和完整审核参考答案，不能偷换成另一个题目。

## 测试与用户验收

- 新增 animation_engine/tests/test_unified_classroom_flow.py：正负测试覆盖未审核、伪造来源、跳步、误引用、修改公式、错误题干、错误参考解答、目录逃逸、全局事件顺序与积分数学正确性。
- 新增 .github/workflows/v2-6-1-unified-classroom.yml：新专项测试、旧教师/导演/动画回归；真正 MathTex 测量、混合完整视频渲染、跨段擦板时序、固定题干与 FFprobe/FFmpeg 抽帧。
- **只有代码与真实 MP4 完整通过以后**才进入最终视觉验收。不能将因 GitHub Actions 托管 runner 尚未分配而失败的结果说成已通过。

## 固化的老规则

白板、题干居上且紧凑、数学符号使用标准 MathTex、数学公式居中或在已有图文区域内合理居中；短公式适度同排、长公式充分展开；核心知识点展示可迁移的定义/定理/性质及公式而不是本题运算口令；已写内容保留至安全擦板，跨页/跨段引用来源可信；TTS 发音与显示公式分离，字幕只能根据实际已录教师语音生成。
