# 数学动画执行模块 V1 第二阶段：真实课堂视觉设计

> 2026-10-30 用户已批准。基础分支：feature/animation-engine-v1-step1。此规范涵盖 2.1—2.5；本 PR 仅实现 2.1。

## 教学定位与不可更改的规则

面向基础薄弱至中等水平学生，默认“适度精讲”：解释关键思路、首次方法和关键变形，必要计算不跳步，基本运算不机械重复。数学教师模块负责内容正确性；动画不得补题、篡改推导或发明口播。

白色 #FFFFFF 背景、深灰 #1E293B 公式、当前重点蓝色 #2563EB、随后复原。纯公式书写，不显示手/笔尖；所有数学字符与几何标签必须真实 TeX/MathTex，不能显示 TTS 音译字；极限使用规范下标位置；题干一般居中，过长时左对齐；答案无框。字幕与板书独立：字幕只显示真实口播的内容与数学 TeX；真实语音时间码还未生成。

## 确认的视觉方案：B，数学结构分段书写

先正确编译/定位整式，再依据经过验证的数学子式标记依次 Write；没有可信分段标记时整条 Write，禁止自动字符串切片制造错误中间等式。有明确子式映射时局部蓝色强调；不明确就强调整式，恢复原色。不提前显示未来步骤。分段、式子、对象、来源、口播锚点均需追溯。

## 现有合同对接

视觉导演 StoryboardPlan v1.0 含 header、theme、regions、scenes、captions；动画 ExecutionPlan v1.0 含动作、对象状态、来源和 SHA，但是不含完整画布坐标，故渲染须同时读取二者并校验整份合同与 SHA。两者的 schema、数学内容及 object_id 不得被渲染层静默修改。口播仅有 semantic_anchors_only，严禁伪装真实秒级同步。

## 长计算/各题型板书

连续推导：有空间则保留上一行和原式，下方逐步写；长公式优先在完整数学结构边界换行，不拆分分式和矩阵对象；仍不足则在完整步骤边界切幕。新幕保留计算对象与必要前置结果，不把几十行公式无限缩小；完整历史仍在前一幕。

分项极限、积分、分类讨论：先展示各项，上方尽量保留，下面依次完整计算，每项结果留下，最终合并。矩阵运算：前后状态并排与当前行突出；证明：保留假设和关键引理；几何与多元：图形区和算式安全分离，数字与标签真实 MathTex 并避免线点重叠。知识区（scratch）按需临时显示，随后受控归档。

## 子阶段、验收

- 2.1：真实 Manim MathTex 编译、测量、单个真实公式的静态 PNG 与 metadata；分式/极限/积分/矩阵验证；明确超宽、危险 TeX、缺失环境等错误；不在此阶段生成假动画。
- 2.2：按可信数学子对象分段写入、局部高亮恢复、同名符号精确选中。
- 2.3：真实字体与包围盒布局、题干和字幕混排、等号对齐、长式合法换行及避让。
- 2.4：拆项逐项详细计算、滚动、满屏切幕、关键上下文承接。
- 2.5：多类型全流程教学与视觉回归，测试包含极限、积分、矩阵和长证明。

不接入 AI、TTS、音频对齐或通用互联网 TeX 服务。外部不可信 TeX 必须另行沙箱限制 CPU/内存/运行时，当前允许的仅是离线可信教学数据的受控渲染。各小阶段有独立计划、测试、实际输出证据和 PR；不能因 JSON 测试通过就宣称课堂完成。
